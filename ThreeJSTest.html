Power BI Desktop · validação de WebGL

ThreeJSTest

Guia técnico para criar, compilar e importar um visual mínimo com um cubo 3D que gira e acompanha o tamanho do espaço visual.

Objetivo: validar o caminho de renderização local Three.js → WebGL dentro de um visual do Power BI. Este projeto não usa campos de dados, DAX, modelos externos nem CDN.

Compatibilidade e preparo

O exemplo usa Power BI Visuals Tools 7.2.1, API do Power BI 5.11.1, Three.js 0.186.1 e tipos @types/three 0.186.0. O template atual declara TypeScript 5.5.4, abaixo da versão mínima declarada pelos tipos do Three.js; por isso atualizamos somente o compilador para TypeScript 5.9.3.

O Three.js atual exige WebGL 2. O visual precisa ser executado em um Power BI Desktop com WebGL 2 disponível no ambiente. Consulte a documentação do WebGLRenderer.

O template PBIVIZ já configura o empacotamento dos módulos npm em JavaScript. Para este exemplo não é preciso acrescentar configuração de webpack, URL externa ou privilégio no Power BI.

1. Executar o projeto desta pasta

O projeto foi gerado com pbiviz new ThreeJSTest e está pronto na pasta ThreeJS. Abra o PowerShell nessa pasta e execute:

$env:NODE_USE_SYSTEM_CA = "1"

npm.cmd install
npm.cmd run check
npm.cmd test
npm.cmd run package

A variável NODE_USE_SYSTEM_CA permite que o Node/npm use os certificados confiáveis do sistema. Ela é útil se a instalação falhar com um erro de certificado HTTPS. Os executáveis .cmd contornam a política local que pode bloquear npm.ps1 no PowerShell.

No Prompt de Comando (CMD), os comandos npm e PBIVIZ podem ser escritos sem o sufixo .cmd. Use set NODE_USE_SYSTEM_CA=1 para definir a variável nessa sessão.

2. Arquivos do visual

Os quatro arquivos abaixo já estão implementados nesta pasta. O package-lock.json registra as dependências instaladas. O teste de lógica está em test/selfcheck.mjs; ele simula somente o renderer, usando as classes reais do Three.js para verificar animação, enquadramento e descarte.

src/visual.ts — cena, cubo, redimensionamento e animação 
"use strict";

import powerbi from "powerbi-visuals-api";
import * as THREE from "three";
import "../style/visual.less";

import VisualConstructorOptions = powerbi.extensibility.visual.VisualConstructorOptions;
import VisualUpdateOptions = powerbi.extensibility.visual.VisualUpdateOptions;
import IVisual = powerbi.extensibility.visual.IVisual;

export class Visual implements IVisual {
    private scene: THREE.Scene;
    private camera: THREE.PerspectiveCamera;
    private renderer: THREE.WebGLRenderer;
    private geometry: THREE.BoxGeometry;
    private material: THREE.MeshStandardMaterial;
    private cube: THREE.Mesh;
    private animationFrameId = 0;

    constructor(options: VisualConstructorOptions) {
        this.scene = new THREE.Scene();

        this.camera = new THREE.PerspectiveCamera(45, 1, 0.1, 100);
        this.camera.position.z = 3;

        this.renderer = new THREE.WebGLRenderer({
            antialias: true,
            alpha: true
        });
        this.renderer.setSize(1, 1);
        this.renderer.domElement.style.display = "block";
        options.element.appendChild(this.renderer.domElement);

        this.geometry = new THREE.BoxGeometry(1, 1, 1);
        this.material = new THREE.MeshStandardMaterial({
            color: 0x2589ff,
            roughness: 0.5
        });
        this.cube = new THREE.Mesh(this.geometry, this.material);
        this.scene.add(this.cube);

        const directionalLight = new THREE.DirectionalLight(0xffffff, 3);
        directionalLight.position.set(3, 4, 5);
        this.scene.add(directionalLight);
        this.scene.add(new THREE.AmbientLight(0xffffff, 1));

        this.animate();
    }

    public update(options: VisualUpdateOptions): void {
        const width = Math.max(1, options.viewport.width);
        const height = Math.max(1, options.viewport.height);

        this.renderer.setSize(width, height);
        this.camera.aspect = width / height;
        this.camera.position.z = 3 / Math.min(1, this.camera.aspect);
        this.camera.far = this.camera.position.z + 10;
        this.camera.updateProjectionMatrix();
    }

    private animate = (): void => {
        this.cube.rotation.x += 0.01;
        this.cube.rotation.y += 0.015;
        this.renderer.render(this.scene, this.camera);
        this.animationFrameId = requestAnimationFrame(this.animate);
    };

    public destroy(): void {
        cancelAnimationFrame(this.animationFrameId);
        this.geometry.dispose();
        this.material.dispose();
        this.renderer.dispose();
        this.renderer.domElement.remove();
        this.scene.clear();
    }
}

3. Compilar e empacotar

Na pasta ThreeJS, instale as dependências e rode a verificação do TypeScript:

$env:NODE_USE_SYSTEM_CA = "1"

npm.cmd install
npm.cmd run check

Se o TypeScript não mostrar erros, gere o pacote:

npm.cmd run package

No CMD, os comandos de compilação e pacote solicitados são:

set NODE_USE_SYSTEM_CA=1
npm install
npm run package

Local do pacote gerado

O PBIVIZ grava o arquivo dentro da pasta dist. O nome combina o GUID e a versão definidos no arquivo de metadados:

dist/threeJSTest45CC1E0F2B4D4A8B9C6D7E8F9012A3B4.1.0.0.0.pbiviz

4. Importar no Power BI Desktop

  1. Abra o relatório e acesse Arquivo → Opções e configurações → Opções → Arquivo atual → Configurações do relatório.
  2. Habilite Desenvolver um visual / Develop a visual para a sessão atual.
  3. No painel Visualizações, abra … → Importar um visual de um arquivo.
  4. Selecione o arquivo .pbiviz dentro de dist e confirme a importação.
  5. Selecione o ícone do visual recém-importado para inseri-lo no relatório. Não adicione campos.
  6. Redimensione o visual em paisagem e retrato para conferir o canvas.

Veja as instruções oficiais de importação.

5. Troubleshooting

SintomaO que verificar
Tela brancaConfirme que o pacote foi compilado e importado novamente. Confira se o construtor não relatou falha ao criar o contexto WebGL. Teste uma nova instância do visual.
WebGL não apareceO renderer atual exige WebGL 2. Verifique se o ambiente do Power BI Desktop oferece esse contexto. Uma falha ao criar WebGLRenderer impede a renderização.
Erro de TypeScriptConfira se TypeScript 5.9.3 está instalado e rode npx.cmd tsc --noEmit na pasta do projeto. O tsconfig.json original já tem ES2022 e DOM.
Módulo three não encontradoNa pasta que contém package.json, rode npm.cmd install e confirme npm.cmd ls three @types/three.
pbiviz package falhaConfira o diretório atual, a saída do TypeScript e os metadados do pbiviz.json. Para mais detalhes, rode npm.cmd run package -- --verbose.
Visual aparece, cubo nãoConfirme supportsLandingPage e supportsEmptyDataView. Verifique no código a posição da câmera em Z positivo, as luzes e o loop de animação.
Content Security Policy (CSP)Confira a diretiva indicada no erro do host. O exemplo importa Three.js via npm e não carrega scripts externos. O visual não precisa acessar uma CDN.
Tamanho do canvas incorretoO método update precisa usar as dimensões de options.viewport, chamar renderer.setSize() e atualizar o aspecto e a matriz de projeção da câmera.
Certificado HTTPS no npmNo PowerShell, defina $env:NODE_USE_SYSTEM_CA = "1" antes de instalar. Não desative a verificação TLS do npm.
Aviso de certificado ou pwsh ao empacotarUma tentativa de gerar certificado local ou uma mensagem sobre recursos opcionais pode aparecer. Confirme se a saída informa Build completed successfully e se o arquivo .pbiviz foi criado em dist.
Critério de sucesso: importar o arquivo .pbiviz, inserir o visual sem dados, observar o cubo azul girar nos eixos X e Y e confirmar que o canvas acompanha o redimensionamento.

Teste de lógica realizado: compilação TypeScript, pacote PBIVIZ, dimensões zero, enquadramento estreito, reutilização de objetos e liberação no método destroy.

A geração do pacote foi validada. A renderização dentro do Power BI Desktop ainda precisa ser confirmada no ambiente que executará o visual.
